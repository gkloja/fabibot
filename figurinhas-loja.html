Figurinhas

Transforme mídia em figurinha.

A criação de stickers é um dos recursos mais simples da Fabi Bot.

Como funciona a Loja de Figurinhas

  1. Envie uma imagem, vídeo ou GIF no grupo WhatsApp.
  2. Responda à mensagem com /salvarfig para gravar na loja.
  3. Acesse a loja virtual para visualizar suas figurinhas.
  4. Selecione as figurinhas e adicione ao carrinho (15¢ cada).
  5. Finalize a compra e receba as figurinhas no grupo.

Cada figurinha custa 15¢

O pagamento é simulado no site. Após a confirmação, as figurinhas selecionadas são enviadas via comando /enviafig para o dono do grupo.

📁 Pré-visualização Automática

Ao carregar a página, as miniatura das figurinhas já aparecem na view "previa". Clique na figurinha para ver o visual "exemplo".

🛒 Carrinho Inteligente

Selecione múltiplas figurinhas. O carrinho acumula o total (15¢ por figurinha) e permite remover itens antes do checkout.

🔐 Apenas para o Dono

Os comandos /salvarfig e /enviafig só funcionam para o dono do grupo (configurado no backend).

Comandos Disponíveis

  • /salvarfig - Salva a figurinha respondendo a uma mídia (grava áudio se houver)
  • /enviafig - Envia as figurinhas da loja uma por uma para o dono
  • /testpack - Teste de pack nativo de figurinhas
